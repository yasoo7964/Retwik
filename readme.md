【Ｒｅｔｗｉｋ　－　ＸからＴｉｋＴｏｋへリポスト　：　Ａｎｄｒｏｉｄライフハックアプリ】<br>
<br>
Ｘ（Ｔｗｉｔｔｅｒ）からＴｉｋＴｏｋへリツイートができます。<br>
厳密には「リツイートする様な感覚で転載ができる支援ツール」です。<br>
公式アプリにてつぶやきの右下にある共有メニューから「その他の方法で共有」→「このアプリを選ぶ」と進んで下さい。<br>
スクリーンショットを撮って（トリミングして）ＴｉｋＴｏｋアプリへ転送してくれます。<br>
もしくは「動画で転送する」を選べば当該ポストに貼り付けられた動画をダウンロードしてＴｉｋＴｏｋアプリへ転送してくれます。<br>
直接本アプリを起動しても使えます。<br>
